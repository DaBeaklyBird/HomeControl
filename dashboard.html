App & game time
Foreground time only. Pauses after 60 seconds without keyboard or mouse input. Controller-only games can appear idle. Budgets reset at midnight on the computer.


Daily app budgets
App mode caps the shared CPU budget of matching processes. Computer mode lowers CPU performance until midnight or until you remove/raise the expired budget. GPU use is not capped by these timers.


Remote PowerShell
Output appears here.
Commands run with HomeControl's privileges. Each run starts a fresh PowerShell process; no interactive prompts. 30-second deadline, 64 KB output limit.
